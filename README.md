## Investigación

Estudio cómo la IA generativa y los datos mejoran decisiones reales sin sustituir el criterio humano, también cuando los datos viven en sistemas antiguos. Tres líneas:

- **[ProVisio](https://proportione.com/investigacion/provisio/)**: BI mediado por IA generativa para pymes (Design Science Research). Implementación de referencia: [Proportione/proVisio](https://github.com/Proportione/proVisio).
- **[Cognitio](https://proportione.com/investigacion/cognitio/)**: enseñar y evaluar con IA con el marco 20·60·20 (Contexto-Generación-Criterio).
- **[Aviaria](https://proportione.com/investigacion/aviaria/)**: IA responsable en decisiones críticas, empezando por el riesgo de impacto con fauna en aviación civil.

Software abierto: [Proportione/prisma](https://github.com/Proportione/prisma), toolkit en Python para revisiones sistemáticas ([DOI 10.5281/zenodo.19883809](https://doi.org/10.5281/zenodo.19883809)).
